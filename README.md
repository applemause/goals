# Путь

Мобильный трекер личных целей на Cloudflare Workers + D1.

## Что уже работает

- отдельная гостевая доска для каждого нового браузера;
- создание, редактирование и удаление целей;
- этапы с состояниями «впереди / сейчас / сделано»;
- история действий внутри каждой цели;
- D1-миграция и production deployment.

Входа пока нет. Доска идентифицируется случайным ID в `localStorage`, поэтому это только ранний режим без гарантированной защиты. Следующим этапом добавляется полноценная учётная запись и привязка досок к пользователю.

## Команды

```bash
npm run dev
npm run db:migrate
npm run deploy
```
